# DAMP - Digital Asset Management & Property

A full-stack application for property management and agent-client collaboration.

## Project Structure

- `backend/`: Node.js Express API handling authentication, properties, and tasks.
- `frontendApp/`: React Native (Expo) mobile application for agents.
- `frontend/`: Web portal (additional details needed).
- `frontend_AdminPanel/`: Admin operations dashboard.

## Getting Started

### Backend

1. `cd backend`
2. `npm install`
3. Create `.env` from `.env.example`
4. `npm start`

### Mobile App (frontendApp)

1. `cd frontendApp`
2. `npm install`
3. `npx expo start`

## Technologies

- **Mobile**: React Native, Expo, Redux Toolkit
- **Backend**: Node.js, Express, PostgreSQL (Supabase)
- **Styling**: Nativewind / Tailwind CSS
